# 霜璃应用头像

由内置 `image_gen` 工具根据 `../skins/silver-dragon-frames/idle/frame-01.png` 的角色形象生成，原桌宠文件未修改。

生成提示：参考原版银白龙娘，绘制单个居中的正面 Q 版大头及少量肩部；银白蓬松头发、中央呆毛、紫色大眼睛、轻微俏皮微笑、弯曲银色龙角、画面右侧原版花结发饰、尖耳。银白和薰衣草紫色调，简化细节，轮廓清晰，柔和赛璐璐上色，透明背景，无文字、无字母、无底板。头发和龙角完整入镜，小尺寸也能识别。

`dragon-avatar.png` 为生成主图；`scripts/brand-icons.mjs` 仅转换尺寸与容器格式，导出 16、24、32、48、64、128、256 像素 PNG 及多尺寸 `dragon.ico`。
