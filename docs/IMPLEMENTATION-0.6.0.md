## 2026-11-05 已写入的第一批改动

- 核心 Limits.requests 支持 null，显式正整数重新执行上限，重试及摘要计数；协作协调器处理不限。应用数据库 v4 升级先备份，旧请求字段迁移为不限。
- providerUsage / addUsage 保留缓存读写、未命中与推理输出可选字段；每次请求记录 started/completed/failed 事件，桌面按 ID 更新 attempts，新增 TokenAnalysis 基础展示。
- TokenMeter 用同配置、同前缀的实际输入作为锚点，新增部分仍保守估算；旧工具结果在压缩前剪枝为附件引用。尚需完整集成核验和优化。
- ToolRegistry 支持经过授权后调用的观察/策略钩子与错误分类；宿主允许的文件只读工具在自动批准模式最多并行三项，按原顺序回传；写入仍串行。重复工具三/五次提醒、八次暂停。
- Dragon worker 开启 MCP 按需发现与加载；独立库默认保持原工具曝光行为。模型只能执行当前已曝光工具，插画通过 toolFilter 仅开放附件读取。
- todo_write 持久化步骤及工具引用；模型声称完成一律先标待验证。完整条件验证器仍未实现，不能宣称目标已经验证成功。
- 插画采用容器宽度 960px 切换双栏/单面板，参考/参数/结果分别挂载且切换不卸载；项目列表可搜索收起。仅编译检查，尚未实际点击验收。
- 插画人设、通用偏好、项目记忆可编辑持久化，下一轮生效。请求带实际模型、LoRA 作者触发词/权重/说明/来源；冲突建议保留供查看应用。
- 插画对话改用 AgentRuntime + 独立 assistant.db，不再每次只拿十条历史；流式文本、取消与用量接入。旧可见对话第一次作为资料传入。
- 插画库 v2 升级备份；Comfy 恢复使用原 endpoint；明确 rejected/execution 错误不再统一视为未知；取消后仍可能运行的任务保持未知。
- 对话增加搜索、最近 100 条分段加载、回到底部；历史聊天可按标题/消息搜索；审批增加提交期间禁用。尚未完成完整的人性化审批卡。
