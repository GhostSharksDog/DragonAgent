# 独立角色插画：已确认需求

在 0.4.0 Agent 交付后实现 0.5.0。停止推进新桌宠动画；原版桌宠与历史素材保留。

- 独立「角色插画」页面，也可由主聊天创建。每个项目拥有对话、角色设定、来源、参数修订和图片历史。
- 用户描述角色、姿势、画师；从 Pixiv 提供最多六张首屏候选，支持继续加载。指定画师时只查该画师与角色的作品，未指定时提供多位候选。
- 独立、无 Node／应用桥接权限的浏览登录窗口。用户登录后复用本机状态，不向模型提供 Cookie。遇访问限制暂停，提供手动作品链接。
- 用户选择一至三张图片后，发送给已配置识图服务提取外观、姿势、服装、配色与构图；显示实际服务和分析结果。
- 用户明确描述优先。默认 Anima Base，使用可编辑 `@画师标签`，区分 Pixiv 昵称与模型标签并标注未核实映射。角色 LoRA 保持用户选择、作者触发词与推荐权重。
- 确认参考选择后自动整理可见正负面提示词并生成一张，不增加每次确认。不训练画师 LoRA，首版不做图生图。
- ComfyUI 已运行则复用，未运行则识别本机安装记录并启动正确 Python／入口／模型输出路径。启动去重、仅本机监听，不安装依赖或升级环境。
- 默认 1024×1024、30 步、CFG 4、dpmpp_2m_sde_gpu、normal，GPU 串行。不加载 Wan／ToonOut，不要求全身／透明背景。
- 持久化 prompt_id、实际参数、模型及 LoRA 哈希；恢复先核对任务，不重复未知副作用。取消仅作用于本项目。
- 功能完成后集中验收真实 Pixiv、识图、ComfyUI 冷启动和 Anima 单图；分别发布安装包、ZIP、SHA256、截图并提交 GitHub。

本机 Comfy Desktop 安装记录：`%APPDATA%\Comfy Desktop\installations.json`；安装目录 `E:\Comfy-Desktop\ComfyUI-Installs\ComfyUI`。存在 standalone-env 和旧 .venv，必须检测实际可用解释器，不能硬编码旧路径。
