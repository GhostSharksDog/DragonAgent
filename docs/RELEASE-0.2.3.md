# DragonAgent 0.2.3

输入框整合模型与权限选择，窗口采用统一主题标题栏和霜璃头像。原桌宠图像、动画与手势保持不变。

## 输入栏与两种模型通道

侧栏不再放模型选择。输入栏左侧为添加资料、权限、工作目录；右侧为模型按钮和 36×36 发送按钮。权限说明收进菜单，三个级别的实际授权规则不变。

模型菜单分为 **Codex** 与 **其他模型** 两个页签。其他模型使用自己的 API 配置；同一 Dragon 聊天切换模型时保留历史、草稿、附件与权限，下一条消息生效，内核根据新窗口压缩并清理不兼容的供应商续接字段。

Codex 模型列表来自当前 app-server 的 `model/list`，支持分页、刷新和可见错误；不是写死的名称列表，也不代表账号对每个模型都有使用权限。列表展示的实际模型决定推理滑条的有效档位。最高档触发短暂光晕和星光动画，尊重系统减少动态效果设置。所选模型与推理档位在当前会话保存，并作为新 Codex 聊天的默认选择；`thread/start`、`thread/resume` 与 `turn/start` 都传递相应配置。

Codex 与 Dragon 互换时，选择目标模型会携带可审核的文字摘录新建聊天；原聊天、草稿与附件留在原处。新聊天从全请求批准开始，不复用原生执行状态。运行中或等审批时不能修改模型。

## 窗口与头像

Windows 使用隐藏标题栏与原生窗口按钮覆盖层，窗口控件、页面、首次背景同步使用实际主题。工作台关闭后收进托盘。菜单通过独立浮层避开输入框裁切，支持键盘选择、焦点返回和窄窗口滚动。

头像使用内置 imagegen 参考原版银白紫瞳龙娘生成，原图与提示说明在 `assets/branding`。PNG 主图派生 16/24/32/48/64/128/256 像素图标与 ICO，覆盖侧栏、窗口、托盘、EXE 和安装包。EXE 启用资源编辑，未配置代码签名。

## 集中验收

功能完成后复用现有 29 项检查，以及实际 Electron 的附件、权限、跨窗口、子任务协作、透明背景与手势流程。新增一个集中界面脚本 `scripts/chrome-check.mjs`，覆盖模型切换、16K 窗口压缩、通道互换、草稿保留、输入法、停止、菜单键盘、Codex 真实模型目录、推理滑条与最高档动画、浅深主题、最小窗口、150% 页面缩放、最大化及关闭到托盘。

模拟服务与真实模型验收分别记录。`scripts/model-live023.mjs` 使用真实应用的原加密环境，检查 Codex 两个推理档位的连续回复，并核对该会话的原生记录中的模型和强度；另验证已配置的 DeepSeek 回复。只记录非敏感结果，结束后恢复原模型默认值。

发行版、图标资源和 SHA256 结果由 `scripts/release-check.mjs` 检查；固定入口替换前备份旧版本。原数据、密钥与记忆继续使用。

最终结果（2026-10-30）：29 项现有检查通过；最终发行程序的界面、附件与三档权限集中检查通过。Codex `gpt-6.1-sol` 的 `low` / `medium` 连续请求通过，原生会话记录确认模型与强度；DeepSeek `deepseek-flash` 回复通过。EXE 和安装包内的 7 个头像尺寸逐一匹配，4196 个应用文件扫描未发现 DSH/Cordis 执行依赖。

原生窗口截图确认浅深标题栏与页面一致；标题栏命中测试返回可拖动区域，原生双击消息可最大化。Windows 拒绝验收脚本激活前台窗口，因此物理鼠标拖动未能自动验证，不计作已通过。桌宠在浅深桌面底板上的四角合成像素均通过。

本机没有全新 Windows 虚拟机；全新系统安装/卸载流程未在虚拟机验收。150% 界面检查使用页面缩放，Windows 实际 DPI 的合成截图另按本机显示器设置检查。
